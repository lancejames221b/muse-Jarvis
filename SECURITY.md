# Security

This project is designed to run on a private network (Tailscale), with its
HTTP API bound to loopback by default and guarded by a Bearer <redacted> Even so,
if you find a vulnerability, please tell us privately so it can be fixed
before it's public.

- **Do not** open a public issue for security problems.
- Email the address on the maintainer's GitHub profile, or use GitHub's
  private vulnerability reporting on this repo, with a description and
  reproduction steps.

Supported: the latest commit on `master`. Older checkouts are on their own.
